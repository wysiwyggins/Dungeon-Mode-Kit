# modules

Met with Six today and talked about what would need to happen for a hosted version. The editors will need a lot of work to go from something that just spits out json to the clipboard to something that actually builds a prototype folder and lets a user download that in a manageable form. 

A suggestion was to use [OPFS](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system) to build the prototype folder locally in browser, which I'm looking into now. 

It was a little embarassing to let someone look under the hood into my nest of spiders, especially engine.js which is now enormous. I'm going to take their advice and try to refactor the javascript files to [ES6 modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules).
